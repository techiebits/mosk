# LLMs

## [llms-txt](https://llmstxt.org/)

Proposed standard to add `/llms.txt` markdown fileto web sites to provide LLM-friendly content.

Format of a llms.txt file spec:

```md

# Title

> Optional description goes here

Optional details go here

## Section name

- [Link title](https://link_url): Optional link details

## Optional

- [Link title](https://link_url)

```

This section contains collection of useful `llms.txt` specs for MCP accesses.
